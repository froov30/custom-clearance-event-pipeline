# Customs Clearance Event Pipeline

> **Synthetic data.** Every event is generated by a simulator. The formats are real (ISO 6346, UN/LOCODE, HS codes); the data is not.

An event-driven pipeline (Kafka → validator → processor → MongoDB, plus monitor and API) that derives each shipment's
customs clearance state from an immutable event log, tolerating duplicate, late and out-of-order events.

**Status:** under construction. See [docs/TASKS.md](docs/TASKS.md). Only what is built and verified is described here.
